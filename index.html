About Me

The Website

This website might function as a blog of sorts for random stuff I would like to talk about (as well as a place to host my public files). Look around if that sounds interesting to you.

The site is quite simple, created using the Zola static site generator. Zola is a very nice tool which I must recommend. It allows me to quickly add files to my website in markdown format and preview them on localhost. Moreover, it follows symlinks to my files, so I don't need to update the website every time I update a pdf file.
